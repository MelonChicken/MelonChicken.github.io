## <span>GitHub README 초안</span>

# <span>BMOD Motion-Triggered Animal Monitoring Prototype</span>

## <span>Overview</span>

<span>This project implements a lightweight animal monitoring pipeline that detects activity, records event-centered clips, tracks the target animal, extracts trajectory features, and prioritizes uncertain events for human review.</span>

## <span>Motivation</span>

<span>Long animal videos contain large amounts of idle footage. Running object detection and behavior classification on every frame wastes computation and storage.</span>

## <span>Pipeline</span>

1. <span>Capture or load video.</span>
2. <span>Detect motion in a region of interest.</span>
3. <span>Start an event with a lookback buffer.</span>
4. <span>Run object detection and tracking.</span>
5. <span>Save the event clip and trajectory.</span>
6. <span>Extract motion features.</span>
7. <span>Classify the event or detect noise.</span>
8. <span>Send low-confidence events to a review queue.</span>

## <span>Evaluation</span>

- <span>event precision</span>
- <span>event recall</span>
- <span>false trigger rate</span>
- <span>tracking failure rate</span>
- <span>processing speed</span>
- <span>percentage of footage skipped</span>
- <span>human review rate</span>

## <span>Portfolio Statement</span>

<span>Built an edge-to-laptop animal monitoring prototype that reduces idle-video processing through motion-triggered recording and combines object tracking, trajectory features, and uncertainty-based human review.</span>

## <span>간결한 블로그 초안</span>

### <span>장시간 동물 영상은 먼저 줄여야 한다</span>

<span>동물 행동 분석 프로젝트에서는 모델 성능보다 먼저 장시간 영상을 어떻게 처리할지가 문제가 된다. 카메라를 몇 시간 동안 켜 두면 대부분의 frame은 행동이 없거나 관심 대상이 화면에 없는 구간이다.</span>

<span>BeeMonitor는 평상시에는 가벼운 motion detection만 수행하고, 움직임이 감지되면 lookback buffer를 포함해 full tracking mode로 전환한다. 이후 YOLO detector와 custom tracker로 trajectory를 만들고, 길이·속도·방향·nest 접근 거리 같은 feature를 계산해 실제 행동 event와 noise를 구분한다.</span>

<span>이 구조는 BMOD 프로젝트에도 적용할 수 있다. Raspberry Pi에서는 motion detection과 event clip 저장을 담당하고, 노트북에서는 detector, tracker, behavior classifier를 실행하도록 역할을 분리할 수 있다.</span>

<span>이번 주에는 전체 behavior classifier보다 motion-triggered recording과 trajectory review까지 구현한다. confidence가 낮거나 tracking이 끊긴 event만 사람이 검토하도록 review queue를 만들면 장시간 영상 수집과 labeling automation을 하나의 pipeline으로 연결할 수 있다.</span>
